# Greek core / evidence library

The word “official” is not used here to mean canonical. Greek myth survives in different genres, places, periods, and media; sources can disagree without one being the definitive version. This shelf is the evidence base for lesson claims.

## C. Discovery resources (not final authorities)

- **Perseus Digital Library / Scaife Viewer / Perseus Catalog**: locate Greek texts, translations, catalog metadata, and stable passage identifiers. Always record which translation/edition is being cited; the library hosts texts with different editorial histories and rights.
- **Theoi Classical Texts Library**: convenient topical discovery index for translated ancient passages. Follow its references back to the ancient work and edition before making a lesson claim.
- **Digital Periegesis of Pausanias**: useful for place-based discovery and linked data, with the original travel text as the evidence.
- **MANTO**: useful for finding named entities and attestations; cite the attestation, not merely the database entry.

## D. Evidence-ranking rule for lesson claims

For each claim, store one or more references and tag the claim’s evidence type:

1. **Primary literary evidence** — quote or paraphrase a specific ancient passage with its work and locator.
2. **Material / epigraphic evidence** — identify the object or inscription, date/context, collection or publication record, and limits of interpretation.
3. **Scholarly interpretation** — name the scholar and exact publication/page or chapter; distinguish interpretation from what the primary source directly states.
4. **Modern reception** — store separately in the flavor library and use only to make a clearly labeled comparison.

When two ancient sources differ, retain both attestations and describe the difference. Never use a modern plot summary to silently fill a gap in an ancient source.
