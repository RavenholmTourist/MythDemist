## Decision rule

When the learner's first export arrives: rank traditions by (arc completion,
quiz weakness, drop-off points). Author tier-2 for the top 2-3 feasible
traditions, sourcing new corpus texts first where the gap column says so.

## Required before any tier-2 authoring

- Same AGENTS.md evidence rules: verbatim quotations, named locators,
  genre separation, living-tradition provenance care.
- New sources get manifest records + segmenters + provenance notes first.
- Each new pack ships with a digest-guarded author script and regressions.
